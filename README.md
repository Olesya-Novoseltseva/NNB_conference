# От целых чисел к конечным полям

Интерактивное пособие по теме:

> Алгоритмическая неразрешимость диофантовых уравнений над кольцом целых чисел и NP-полнота их аналогов над конечными полями: сравнительный анализ.

Продукт показывает границы вычислимости и сложности, а не пытается создать невозможный универсальный решатель над `Z`.

## Что умеет приложение

- Решает линейные диофантовы уравнения `a*x + b*y = c` через расширенный алгоритм Евклида.
- Показывает ограниченный перебор над `Z` в окне `[-N, N]^k` и объясняет, почему это не доказательство отсутствия решений.
- Работает с системами многочленов над простым конечным полем `F_p`.
- Проверяет готовое свидетельство решения и перебирает малые пространства `F_p^n`.
- Демонстрирует учебное сведение маленькой `3-SAT` формулы к MQ-системе над `GF(2)`.
- Показывает рост пространства поиска `p^n`.

## Запуск

```bash
npm install
npm run dev
```

Для проверки сборки:

```bash

```

## Публикация на GitHub Pages

В репозитории настроен деплой через GitHub Actions (файл `.github/workflows/deploy-pages.yml`):

1. Загрузите код в репозиторий на GitHub (ветка `main` или `master`).
2. Откройте **Settings → Pages** для репозитория.
3. В разделе **Build and deployment** выберите источник **GitHub Actions** (не «Deploy from a branch»).
4. После успешного запуска workflow сайт будет доступен по адресу вида `https://<user>.github.io/<repo>/`.

Особый случай: если имя репозитория оканчивается на **`.github.io`** (персональный или организационный сайт), workflow выставляет корневой путь **`/`**, и сайт открывается по `https://<user>.github.io/`.

Локально можно проверить пути ассетов так же, как в CI: задайте `BASE_PATH` под имя репозитория на GitHub (со слешами в начале и в конце для проектного сайта):

```bash
# Bash (Linux, macOS, Git Bash)
BASE_PATH=/имя-репозитория-on-github/ npm run build
npx vite preview
```

```powershell
# PowerShell
$env:BASE_PATH = "/имя-репозитория-on-github/"
npm run build
npx vite preview
```

В корне `public/` есть пустой файл `.nojekyll`, чтобы GitHub Pages не прогонял раздачу через Jekyll.

## Ограничения

- Приложение не решает общую 10-ю проблему Гильберта: такого алгоритма над `Z` не существует.
- Для `Z` реализованы только специальные алгоритмы и конечные эксперименты.
- Для конечных полей реализованы простые поля `F_p`, где `p` является простым числом.
- Ввод многочленов поддерживает ограниченный синтаксис: числа, переменные, `+`, `-`, `*`, `^`, скобки и знак `=`.
- MQ/NP-модуль является учебной демонстрацией идеи, а не инструментом для больших криптографических задач.

## Связь с прошлой работой

Предыдущая работа объясняла 10-ю проблему Гильберта через машины Тьюринга, полуразрешимость и диофантово моделирование. Этот сайт добавляет программный слой:

- Над `Z` показывает решаемый подкласс и ограниченный эксперимент.
- Над `F_p` показывает конечность области поиска и проверку свидетеля.
- Через MQ объясняет, почему конечность не означает практическую легкость.

## Маршрут демонстрации

1. Открыть карту темы.
2. Решить `14x + 21y = 7`.
3. Показать отказ для `6x + 10y = 7`.
4. Запустить ограниченный перебор над `Z`.
5. Проверить систему над `F_2`.
6. Открыть MQ-модуль и показать проверку свидетельства.
7. Завершить сравнением: над `Z` общий алгоритм невозможен, над `F_p` задача разрешима, но MQ в общем случае NP-полна.
